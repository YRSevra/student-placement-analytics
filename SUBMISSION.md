## Description (487 characters):
This interactive dashboard explores factors associated with student placement outcomes using 215 real campus recruitment records from Jain University. It compares academic performance, experience, and disciplines across placed and unplaced students with interactive filters and exception analysis. One notable pattern observed was that work experience was associated with an 86.5% placement rate versus 59.6% without. The dashboard highlights associations rather than claiming causation.
